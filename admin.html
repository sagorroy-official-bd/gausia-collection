📁 Original Folder - সংরক্ষণ (১ সেট) - ছোট ছোট করে জমা থাকবে

সেলার যা পাঠাইছে হুবহু থাকবে, কখনো বদলাবে না। ছোট কার্ডে জমা থাকবে, জায়গা কম নিবে। 👁️ দেখুন চাপলে পুরা তথ্য খুলবে। ✅ Approve করলে আরেকটা কপি Customize এ যাবে, ওখানে পুরাটা দেখা যাবে।

সেলার এখনো কোনো পণ্য পাঠায় নাই।

✏️ Customize Folder - দারাজের মতো করে এডিট করেন

Original থেকে Approve করা কপি এখানে আসে। ছবি Resize - Contain, পুরা শাড়ি দেখা যাবে। কয়েন / ভাউচার থাকবে না। ✏️ Edit চাপলে নিচে সব ফিল্ড খুলবে। প্রতিটা ছবির উপরে ✕ আছে - যেই ছবি ভালো না, ওইটার ✕ চাপলেই শুধু ওইটা ডিলিট হবে। তারপর 💾 Save চাপলে সেভ হবে। তারপর নিচে ৩টা Publish বাটন - Flash / All Category / উভয়। উভয়ে পাঠালে ২টা আলাদা আলাদা কপি হবে, একটা থেকে ডিলিট করলে আরেকটা থাকবে।

কোনো পণ্য নাই। Original থেকে ✅ Approve চাপেন।
